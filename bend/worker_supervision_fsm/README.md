# Worker supervision in Bend (experiment)

Loop 2 of the statechart-then-verify layer, beside loop 1's
`bend/work_item_fsm`. **Status: experimental.** The Bend model is CI/spec
evidence; it does not run, resume, kill or admit anything.

```
docs/fsm/worker-supervision.svg  <- the statechart (generated from src/z0int/fsm/worker_supervision.py)
fsm.bend                         <- worker step/run, Lease (lstep/holds), S25 Device (peff/pstep)
LAWS.bend                        <- 19 claims under laws W1-W6 (the owner's spec; do not weaken to pass)
PROOF.bend                       <- proofs, generated by gen_proof.py (it stamps the per-state/per-event cases)
mutations.py                     <- 17 broken variants of fsm.bend; each must make PROOF.bend fail
receipt.json                     <- `hermes bend verify` receipt (PASS, kernel-rechecked)
```

Bend **2.0.34**, Lean 4.34.0 for `--verdict`. Bend and Lean exist only on
groot: this is the declared toolchain exception to W4, so the proof steps run
on groot under `heavy.lock`. Everything else (Python twin, replay tests)
runs on the MBP through `scripts/fleet run` / `fleet-build`.

## Run

```bash
cd bend/worker_supervision_fsm
python3 gen_proof.py                                         # after editing proof logic
bend PROOF.bend                                              # ALL PROOFS CHECK (~0.3 s)
PATH=/usr/bin:$PATH:~/.elan/bin bend PROOF.bend --verdict    # kernel recheck
rm -f receipt.json && hermes bend verify $PWD --receipt receipt.json
python3 mutations.py --verdict --out mutations.json          # 17/17 must be rejected
```

## States, events, resources

```
Dispatched -> Running(host, heartbeat, bg) -> Completed | Interrupted | Stalled
Stalled -> Running (Beat) | Interrupted (silent for 2 x limit)
Interrupted -> Overdue (past the limit: needs Kevin) | Resumed(by, adopts bg) | Abandoned (bg == 0)
Completed -> Integrated | Abandoned (bg == 0)
Lease  Free | Held(owner): Acquire / Release / Reclaim(dead)   (worktree/branch; also the phone install lock)
Device Dev(lock, fg): Lock / Unlock / Peek(app) / Install / Input(app)   (the owner's S25)
```

`bg` counts background processes the worker left running; `lim` is a
parameter of `step`, so every law holds for every limit (the checker uses 2 h).

## Bend notes learned here

- Constructor names are global: `Phone`, `Look` collided (with a type of the
  same file and with Base). Rename rather than qualify.
- After matching one parameter, a sibling parameter is not a legal scrutinee:
  split into a helper def (`lfree`/`lheld`, `dev_eff`/`dev_step`, `GrootOk`).
- A predicate returning a function type (`T(b) -> Empty`) is `Type`, not `Data`.
- Pattern binders used twice need `+` (`Start{+h, t}`), and so does a
  parameter threaded through recursion (`run(es, +lim, s)`).
