# Work-item lifecycle in Bend (experiment)

Loop 1 of the statechart-then-verify layer (poteto's method, with Bend in
place of TLA+). **Status: experimental.** The Bend model is CI/spec evidence;
it does not run anything, admit anything or mark anything verified_success.

```
docs/fsm/work-item.svg   <- the statechart (generated from src/z0int/fsm/work_item.py)
fsm.bend                 <- the same transition table in Bend (step, run, astep, board_step)
LAWS.bend                <- 15 claims under laws L1-L7 (the owner's spec; do not weaken to pass)
PROOF.bend               <- proofs, generated by gen_proof.py (it stamps the 15 per-event cases)
mutations.py             <- 10 broken variants of fsm.bend; each must make PROOF.bend fail
receipt.json             <- `hermes bend verify` receipt (PASS, kernel-rechecked)
```

Bend **2.0.34** (BendTT). Lean 4.34.0 for `--verdict`. Proofs check in ~1 s,
the kernel recheck in ~6 s.

## Run

```bash
cd bend/work_item_fsm
python3 gen_proof.py                                  # after editing proof logic
bend PROOF.bend                                       # ALL PROOFS CHECK
PATH=/usr/bin:$PATH:~/.elan/bin bend PROOF.bend --verdict   # host clang first, Lean last
hermes bend verify $PWD --receipt receipt.json        # refuses to overwrite: delete first
hermes bend replay receipt.json --project $PWD        # same inputs + verifier -> same verdict
python3 mutations.py --verdict                        # 10/10 must be rejected
cd ../.. && PYTHONPATH=src python -m pytest -q tests/test_fsm_work_item.py   # incl. Bend parity
```

## What is proven and what is only checked

A proven law is a theorem about `fsm.bend`'s own functions over abstract
heads (Nat) and actors. It says nothing about the Python twin, the event
mapping from GitHub/services/logs, or the world.

| law | claim (Bend name) | status |
| --- | --- | --- |
| L1 | a reachable `Merged` item carries an acceptance by an **Owner** actor who is **not its author** (`merged_needs_owner_acceptance`) | **proven** (reachable invariant, induction over every event tape) |
| L2 | verify (CI), integrate (CI/Opus) and accept (Owner) are passed only by a **non-author** of the right role (`verify_gate_not_author`, `integrate_gate_not_author`, `accept_gate_owner_not_author`) | **proven** (all 15 events) |
| L3 | `Verifying -> DraftPR` needs a passing receipt for **exactly the head SHA**; `-> Integrated` needs one for the integration head (`draft_needs_bound_receipt`, `integration_needs_bound_receipt`) | **proven** |
| L4 | a reachable `Deployed` item serves **exactly its integrated head**; observing another head drops it to `Integrated` (`deployed_serves_integrated_head`, `drift_undeploys`) | **proven** |
| L5 | `Interrupted` is no dead end: a coder can always resume it (head kept), the owner can always abandon it, and no other event moves it or loses the head (`interrupted_can_resume`, `interrupted_can_abandon`, `interrupted_exits_keep_head`) | **proven** |
| L5' | interrupted work does not *sit* in `Interrupted` | **checked only**: the model has no clock; the replay checker flags items past a TTL |
| L6 | a reachable `Implementing` item's author is Opus or Sol: free models, Jev, SLMs and chat apps never implement (`implementer_is_coder`) | **proven** |
| L7 | while Kevin is `off`, an owner action is held (item stays in the needs-Kevin queue) (`owner_off_holds`); any non-owner event moves its item exactly like `step`, whatever his availability and whatever else is queued (`queue_never_blocks`); an event for one item never changes another (`board_frame`) | **proven** |
| — | Python `work_item.step` == Bend `step` | **measured**: 400 seeded tapes (5,077 events, all 12 phases reached), identical final states; a test-only sabotaged Python fails the same check |
| — | the laws are load-bearing | **checked**: 10/10 mutations rejected (`mutations.json`, kernel mode). "Rejected" means PROOF.bend stops checking; the reported location is Bend's first failing def, which can be a helper (e.g. the hold-everything mutant fails first in `owner_off_holds`' proof, while the law it actually falsifies is `queue_never_blocks`) |
| — | GitHub/service/log events map faithfully to statechart events | **not proven**; heuristics are in `src/z0int/fsm/replay.py` and listed in docs/fsm/README.md |

## Bend notes learned here

- A wildcard `case _:` in a *proof* does not refine the scrutinee, so a
  proof that splits on an event must list all 15 constructors. `gen_proof.py`
  stamps them.
- `A & B` and `{a == b : T}` are `Type`, not `Data`, so they cannot be
  reused with `+`. The reachable invariant is a Boolean (`inv_b`) reflected
  through `T(b)`, which is `Data`.
- `run(es, s)` takes the tape first: termination reads arguments left to right.
- `hermes bend verify` runs the CLI with an isolated `HOME`; a `bend` wrapper
  that execs `$HOME/.bend/bin/bend.bin` fails with `unsupported_bend`. The
  wrapper on groot now execs `bend.bin` from its own directory.
