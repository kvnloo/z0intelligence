# Canonical intelligence layer

`z0int.intelligence.route(request, snapshot)` is a pure function. The service collects configuration and availability into the snapshot; the authority owns execution identity and persistence. A selection has `executed=false`. Only completed physical execution with its canonical receipt changes that status.

The capability registry is `manifests/capabilities.v1.json`. Evidence is function-specific, repository-relative and integrity checked for automatic routing. Missing evidence returns `PARENT_ONLY`. Tiny or unknown task sizes also remain native. Measured worker quality alone does not establish a delegation benefit: the completed Cerebras reasoning-none cohort remains ineligible, and default/high reasoning is separately excluded.

Jev's existing owner is `z0int.functions.jev`, using `jevkit.client` and its credential resolver. `assess_claim` preserves the evaluated three-way claim contract and reports `SUPPORTED`, `UNKNOWN`, or `UNSUPPORTED`. It is distinct from the existing binary `verify.evidence_sufficiency` function and uses no independent HTTP client or hidden retry. The operator-authorized paid exception applies only to this named verification route. Generic workers remain strictly free-only.

Laya is the local fast path for `verify.evidence_sufficiency`; its broader `verification_needed` routing capability remains experimental and requires evaluated structured state. Uncertain evidence-sufficiency calls escalate to Jev 1.13.0. Local Laya, SolPi, RLM and local model services are not replicated by the remote executor. NanoJev is a legacy benchmark/reproducibility backend only, and Qwen does not acquire production verification eligibility from backend registration. Existing State Packet ownership and rendering remain unchanged; the deleted `verify_gate` is not restored.

`z0int.worker_routing` owns bounded text-worker execution. `manifests/worker_routing.v1.json` owns its provider catalog, free-route allowlist, caps and policy. It cannot grant workers filesystem or tool access. Worker execution and Jev execution are stateless with respect to canonical dispatch persistence.
