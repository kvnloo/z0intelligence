A hand-designed policy network based on masked spatial features.

**Design strategy**
- The first hidden layer creates 28 task-specific detectors:
  - Units `0..9`: one per player column. Outputs `+1` if any treasure is left of the player, `-1` if only right treasure, and `0` if none/same column.
  - Units `10..17`: one per player row. Outputs `+1` if any treasure is above, `-1` if below, else `0`.
  - Units `18..25`: one per player row. Outputs `+1` if an enemy is in the player's current row, else `0`.
  - Units `26..27`: a top/bottom row bias so dodging prefers moving toward the center of the board.
- The second hidden layer simply passes these saturated features through.
- The output layer combines them: treasure units pull left/right/up/down, same-row enemy units strongly push both up and down to dodge, with biases canceling inactive masked units.
